# LabelLens 小红书首发检查清单

## 发布前：公网与核心流程

- [ ] 腾讯云网址能否使用手机流量打开（不要只在同一 Wi-Fi 下测试）
- [ ] 首页是否正常加载，标题、按钮和基础样式是否完整
- [ ] 图片识别是否能创建一次任务并返回结果
- [ ] 识别完成后是否进入人工确认页，确认后数据是否正确写入
- [ ] AI 综合建议是否可以从中断或刷新后恢复
- [ ] 公网地址稳定后，是否已将 `【体验地址待填写】` 替换为实际地址

## 发布前：内容与隐私

- [ ] 所有截图是否裁掉 API Key、taskId、本地路径、认证信息、后台日志、账号信息、浏览器书签和个人头像
- [ ] 截图中的商品名称和数字是否全部来自项目内置虚构示例
- [ ] AI 报告截图是否来自已验证的脱敏夹具，而非临时调用真实接口
- [ ] 图片中文字是否能在手机上看清，尤其是第 4、6、7 张的小字
- [ ] 8 张图片是否均为 1080 × 1440 px，顺序和文件名是否正确
- [ ] 封面标题是否与正文一致
- [ ] 图片和正文是否都明确说明是测试版
- [ ] 是否保留“识别结果需要人工检查”的说明
- [ ] 是否说明 AI 建议只基于用户录入和确认的数据
- [ ] 是否避免医疗、减肥、疾病、疗效和长期健康效果承诺
- [ ] 是否避免对商品做绝对的“健康/不健康”判断
- [ ] 是否没有二维码、夸张求赞文案或未经验证的体验链接

## 发布后

- [ ] 保存发布后的完整帖子截图
- [ ] 保存首批评论和私信反馈，注意遮盖用户个人信息
- [ ] 记录打不开、报错、识别错误和难理解页面的具体位置
- [ ] 将反馈分为：阻塞使用 / 容易误解 / 体验优化 / 新需求
- [ ] 修改产品前先复现问题，不把单条意见直接当成普遍结论
